# シマエナガ 桌面寵物

北長尾山雀（シマエナガ）桌面寵物。完全離線，沒有任何圖片／音頻素材——鳥是 Canvas 程序繪製，叫聲用 WebAudio 合成。支援 Windows / macOS。

## 運行

需要 [Node.js](https://nodejs.org)（18+）：

```bash
npm install
npm start
```

## 打包成安裝檔（可選）

```bash
npm run dist:win   # 在 Windows 上執行，產出 nsis 安裝檔 + portable
npm run dist:mac   # 在 macOS 上執行，產出 dmg
```

## 互動

| 操作 | 效果 |
|---|---|
| 在鳥身上來回滑動 | 撫摸：瞇眼、鼓毛、腮紅、冒愛心、發出舒服的顫音；摸太久會睡著 |
| 單擊 | 嚇一跳，跳起來「チッ！」 |
| 雙擊 | 飛走 |
| 按住拖曳 | 抓起來，可以放到任何地方（例如視窗上緣），過一會兒會自己飛下來 |
| 右鍵（點在鳥身上） / 托盤圖示 | 選單：餵食、叫一聲、飛一飛、睡一會、靜音、大小、專注模式、退出 |

鳥平時會自己發呆、跳跳、啄地、鳴叫、抖毛、偶爾飛到另一邊，很久沒互動就會打瞌睡。餵食時（種子／漿果／麵包蟲）會從天上掉下來，鳥看到後會飛過去或跳過去啄著吃完。

## 作息與專注模式

- 動作很少：大部分時間在發呆，偶爾跳一跳、啄一啄、叫幾聲。
- 1～2 分鐘沒人理牠，會飛到螢幕下方的角落睡覺；之後每 10～30 分鐘醒來活動約 30～50 秒，再回角落睡。
  你一互動（點、摸、拖、餵食、選單指令）牠就醒來。
- **專注模式**（右鍵選單或托盤選單 →「專注模式」）：鳥飛到螢幕右側邊緣的小樹枝上睡覺，一半身體藏在螢幕外，
  不出聲、不攔截滑鼠。再勾一次選單即可退出（選單要從托盤圖示打開）。

## 資源占用

Electron 本身有固定開銷（約 2 億位元組以上），這個程式做了以下優化（Windows 上實測，1920×1080、125% 縮放）：

| 狀態 | CPU（占單核） | 記憶體（私有） |
|---|---|---|
| 優化前（一律 60 幀、全螢幕畫布） | 約 49% | 約 350 MB |
| 現在：睡覺 | 約 1% | 約 130 MB |
| 現在：發呆 / 一般活動 | 約 3% | 約 130 MB |
| 現在：一直在飛（最壞情況） | 約 36% | 約 165 MB |

做法：鳥只畫在一張小畫布上、身體預先畫好重複使用；畫面沒變就不重畫；發呆、睡覺時降低更新頻率；
Windows 上關閉 GPU 加速（畫面簡單，軟體繪製更省）。macOS 沒量測過，保持預設。

## 在 Mac 上量性能

```bash
./perf-mac.sh                                      # 用原始碼啟動，預熱 30 秒後取樣 30 秒
./perf-mac.sh --app /Applications/ShimaEnaga.app   # 量已安裝的 App
./perf-mac.sh --manual                             # 先手動把鳥調到「睡覺 / 專注模式 / 一直在飛」，再按 Enter 取樣
```

輸出每個程序（主程序、GPU、Renderer…）的 CPU%（占單核）、RSS 與 Footprint（最接近活動監視器的記憶體欄位）。
只讀取系統的 `ps` / `footprint` 資訊，不上傳、不修改任何東西。

## 說明

- 本程式**不會**開機自動啟動，也沒有任何常駐／自啟動機制；想用時手動開啟即可。
- 未簽章的 exe 可能被 SmartScreen / 防毒軟體警告（見上方），這是「沒有數位簽章」造成的，不是程式行為問題。

- 視窗是覆蓋工作區的透明視窗，平時滑鼠穿透，只有游標在鳥身上時才攔截，不影響其他軟體操作。鳥站在工作列／Dock 上方。
- 只在主螢幕顯示。
- 設定（靜音、大小）存在使用者資料夾的 `settings.json`。

## 在 Mac 上打包

打包 `.dmg` 必須在 macOS 上進行（Windows / Linux 做不出可運行的 Mac 版）。直接執行腳本：

```bash
./build-mac.sh          # Apple Silicon + Intel 各打一個 dmg，放在 dist/
./build-mac.sh arm64    # 只打 Apple Silicon（M 系列晶片）
./build-mac.sh x64      # 只打 Intel
```

腳本會安裝依賴、打包、做 ad-hoc 簽章、產生 dmg，並清掉中間檔案；它不會讀取你的簽章憑證或鑰匙圈。
（`npm run dist:mac` 也可以，但不含 ad-hoc 簽章與 dmg 重做這兩步。）

沒有 Apple 開發者簽章，第一次開啟會被 Gatekeeper 擋下，二選一：
- 在 Finder 對 App 按右鍵 →「打開」→ 再按「打開」；
- 或在終端機執行 `xattr -cr /Applications/ShimaEnaga.app`。

只想直接跑、不打包：`npm install && npm start` 即可（Mac 上同樣可用）。

沒有 Mac 的話，可把專案推到 GitHub，到 Actions 頁面手動執行 `build` workflow，成品會出現在 Artifacts。
